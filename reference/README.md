## 🎯 CPPG 영역별 학습 로드맵

### 영역 1 (10%) — 개인정보보호의 이해
**참고:** `00`, `01`(제2~4조)
```
□ 개인정보 정의 (제2조)
  ├─ 식별 가능 정보
  ├─ 결합 용이성
  └─ 가명정보
□ OECD 8원칙 (제3조)
□ 정보주체 권리 (제4조)
□ 개인정보 vs 익명정보 구분
```

### 영역 2 (20%) — 개인정보보호 제도
**참고:** `00`, `01`(법체계·권리·벌칙), `04`(CPO·과징금), `05`
```
□ 법령 체계 (특별법·일반법)
□ 정보주체 권리 (열람·정정·삭제·거부)
□ CPO 자격요건 및 독립성
□ 과징금 (최대 3%, 2023 상향)
□ 분쟁조정 및 손해배상
□ 신용정보법·정보통신망법 개요
```

### 영역 3 (25%) — 개인정보 라이프사이클 관리
**참고:** `01`(제15~27조), `03`, `05`
```
□ 수집·이용 근거 (제15조 7가지)
□ 최소 수집 원칙 (제16조)
□ 제3자 제공 (제17조)
□ 목적 외 이용 제한 (제18조)
□ 민감정보 (제23조) — 별도 동의
□ 고유식별정보 (제24조) — 암호화 의무
□ 위탁 및 영업양도 (제26~27조)
□ 파기 (원칙 5일 이내)
□ 동의 방법 (구분·명확화)
□ 신용정보 보유기간 (3~7년)
```

### 영역 4 (30%) — 개인정보의 보호조치 ⭐ 가장 중요
**참고:** `04_안전성확보조치기준.md` 필독
```
□ 내부관리계획 (매년 1회)
□ 접근권한 관리 (최소화·기록)
□ 접근통제 (로그인·암호화)
□ 접속기록 보관 (3개월 이상)
□ 암호화 대상 및 방법
  ├─ 주민등록번호 (저장 시, AES-256)
  ├─ 신용카드·계좌 (저장·전송)
  ├─ 의료정보 (저장·전송)
  └─ 전송 (TLS 1.2 이상)
□ 악성프로그램 방지 (백신·IDS/IPS)
□ 물리적 보안 (서버실·카드키)
□ 재해·재난 대비 (백업·복구)
□ 파기 (복구 불가능한 방식)
```

### 영역 5 (15%) — 개인정보 관리체계
**참고:** `04`(CPO), `02`, `06_관리체계인증.md`
```
□ 정보보호 정책 수립
□ CPO 지정 및 역할
□ 정보보호 교육 (연 2회)
□ 감시·감사·점검
□ ISMS-P 인증 (14개 요소, 3년)
□ ISO 27001/27701 (국제 표준)
□ 개인정보 영향평가(PIA)
□ 보호 수준진단 (A/B/C/D)
□ 정보보호 사고 대응
```
