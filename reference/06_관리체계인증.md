# 정보보호 관리체계 인증 (ISMS-P, ISO 27001/27701)

> 출처: 원이엠에스넷(ISMS 인증), ISO 국제표준기구
> 기준: 2026-05-21
> 반영: CPPG 영역5 (관리체계 15%)

---

## 1. ISMS-P (Information Security Management System - Personal Information)

### 개요

- **정식명:** 정보보호관리체계 인증 (개인정보보호 포함)
- **주관:** 과학기술정보통신부 → 원이엠에스넷(ISMS 인증 기관)
- **목적:** 정보보호 + 개인정보보호 능력 인증
- **대상:** 100인 이상 기업 권장, 공공기관 필수
- **유효기간:** 3년

### ISMS-P 인증 범위

**기본 요소 (14개):**

1. **정책** — 보안정책, 개인정보보호정책
2. **조직** — 정보보호 담당 부서, CPO 지정
3. **위험 관리** — 위험평가, 대응 계획
4. **대응 및 복구** — 사고 대응, 복구 절차
5. **매체 관리** — 저장 매체 안전, 파기
6. **접근 통제** — 권한 관리, 인증
7. **암호화** — 전송·저장 암호화
8. **감시·감시** — 로그 기록·분석
9. **악성코드 방지** — 백신, 침입 탐지
10. **물리 보안** — 서버실, 출입 통제
11. **개인정보보호** — 수집·이용·제공 규정 준수
12. **교육** — 정보보안 교육 (연 2회 이상)
13. **점검·감사** — 정기적 감사
14. **개선** — 지적사항 시정

### ISMS-P 인증 절차

1. **신청** — 인증기관 접수
2. **현장 심사** (예심 + 본심)
   - 예심: 서면 검토 (2주)
   - 본심: 현장 확인 (1~2주)
3. **인증 결정** — 합격·조건부 합격·부적합
4. **유효기간:** 3년 (중간 감시 1회)

### 인증 혜택

- 공공기관 입찰 가산점 (최대 5%)
- 신용보증기금 대출 가능
- 정보보호 법적 책임 경감

## 2. ISO 27001 (Information Security Management System)

### 개요

- **정식명:** ISO/IEC 27001
- **주관:** 국제표준기구(ISO)
- **목적:** 정보보호 국제 표준
- **특징:** 개인정보보호 없음 (정보보호만)
- **유효기간:** 3년

### ISO 27001 vs ISMS-P

| 항목 | ISO 27001 | ISMS-P |
|------|-----------|----------|
| 주관 | 국제(ISO) | 국내(과기부) |
| 개인정보보호 | 미포함 | **포함(필수)** |
| 적용 | 글로벌 기업 | 국내 기업 |
| 신청 | 국제 인증 기관 | ISMS 인증 기관 |
| 비용 | 높음 | 상대적 낮음 |

### 인증 요소 (114개 통제)

- 정보보호 정책
- 조직 및 자산 관리
- 인적 자원 보안
- 자산 관리
- 접근 통제
- 암호화
- 물리·환경 보안
- 운영 보안
- 통신 보안
- 시스템 개발 및 유지관리
- 공급자 관계
- 정보보안 사고 관리
- 사업 연속성 관리
- 규정 준수

## 3. ISO 27701 (Privacy Information Management)

### 개요

- **정식명:** ISO/IEC 27701
- **성격:** ISO 27001의 **확장** (개인정보보호 특화)
- **목적:** 개인정보 국제 표준
- **비교:** GDPR(EU) 수준의 에 개인정보 관리

### ISO 27701 추가 요소

- **DPIA** — 개인정보 영향평가
- **정보주체 권리** — 삭제·열람·이동권
- **가명정보** — 처리·관리
- **국외이전** — 보호 수준 검증
- **개인정보 담당자** — 설치·역할 정의
- **처리 기록** — 개인정보 처리 로그

### 특징

**글로벌 기업 (다국 운영):**
- ISO 27001 + ISO 27701 취득 권장
- GDPR + 각국 법령 준수 용이

**국내 기업:**
- ISMS-P 우선 (법적 기준)
- ISO 27001/27701은 추가 선택

## 4. 한국 개인정보보호위원회 인증 기준

### 개인정보보호 수준진단

- **목적:** 기업·기관의 개인정보 관리 수준 평가
- **주체:** 개인정보보호위원회
- **대상:** 기업, 공공기관
- **주기:** 자율 신청 또는 위원회 요구

**평가 항목:**
1. 법령 준수도
2. 관리체계 수립
3. 기술 보안
4. 전담 조직·인력
5. 개인정보 영향평가(PIA)

**결과:** A/B/C/D 등급 (공개 가능)

---

## 5. 개인정보 영향평가(PIA)

### 개요

- 개인정보 처리 사전 검토
- 고위험 처리(개수 > 100만 명 또는 민감정보) 시 **필수**
- 공개적 투명성 명시

### PIA 항목

1. **처리 목적·근거 합법성**
2. **수집 데이터 최소화 검토**
3. **정보주체 권리 보장**
4. **암호화·접근통제 계획**
5. **침해 위험 분석·대응**

### CPPG 연계

영역5 (관리체계 15%) 출제 근거

## 6. CPPG 영역5 연계

**관리체계 관련 출제 항목:**

| 내용 | 기준 |
|------|------|
| CPO 자격·역할 | ISMS-P 요소 |
| 정보보호 정책 | ISMS-P 기본 정책 |
| 감사·점검 | ISMS-P 요소 + ISO 27001 |
| 개인정보 영향평가 | ISO 27701 + PIA |
| 정보보호 교육 | ISMS-P (연 2회) |
| 보안 사고 대응 | ISMS-P + ISO 27001 |

---

## 7. 실무 선택 기준

**ISMS-P 우선 (국내 기업):**
- 법적 요구사항 충족
- 공공 입찰 가산점
- 비용 상대적 적음

**ISO 27001/27701 권장 (글로벌 기업):**
- 국제 신뢰성
- GDPR 준수 용이
- 해외 고객 신뢰도

**둘 다 권장:**
- 금융사, 대형 IT 기업
- 개인정보 대량 취급 기업
