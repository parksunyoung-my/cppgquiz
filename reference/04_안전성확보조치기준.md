# 안전성 확보조치 기준 (상세)

> 출처: 개인정보보호위원회 「개인정보의 안전성 확보조치 기준」
> 기준: 고시 2020.8.5 개정
> 반영: CPPG 영역4 출제 기준

---

## 1. 내부관리계획 수립·시행

**필수 포함 항목:**
- 개인정보 처리 현황 및 담당자
- 정보보호 교육 계획 (연 1회 이상)
- 유출·침해 대응 절차
- 감시·감사·점검 계획

**공개·관리:**
- CPO 책임 아래 매년 수립
- 분실·도난·유출·변조·훼손 방지책 포함

---

## 2. 접근 권한 관리

**요구사항:**
- 개인정보 접근 권한 최소화 (필요한 직원만)
- 권한 부여·수정·말소 기록 관리
- 정기적 접근권한 검토 (월 1회 이상)

**화면 진출입:**
- 개인정보 취급 화면 접근통제
- 로그인·로그아웃 기록

---

## 3. 접근통제

**잠금 장치:**
- PC: 비활동 15분 후 잠금 설정 (권장)
- 서버실: 카드키·생체인식 등 물리적 통제

**외부 접속:**
- VPN·원격접속 보안 (암호화·인증)
- 공용 충전소 차단

---

## 4. 암호화

**암호화 대상:**

| 대상 | 시점 |
|------|------|
| 주민등록번호, 여권·운전면허·외국인등록번호 | 저장 시 (필수) |
| 신용카드·계좌 정보 | 저장·전송 시 |
| 의료정보, 진료기록 | 저장·전송 시 |
| 비밀번호 | 저장 시 (해시 또는 암호화) |
| 전송 데이터 | 전송 시 (SSL/TLS, VPN) |

**암호화 방식:**
- AES-256 이상 (저장)
- TLS 1.2 이상 (전송)

---

## 5. 접속 기록 보관 및 점검

**보관 대상:**
- 개인정보 접근·다운로드·삭제 기록
- 시스템 관리자 특수권한 사용 기록

**보관 기간:** 3개월 이상

**위·변조 방지:**
- 기록지 파기 불가
- 로그 서버 분리 저장

**점검:** 월 1회 이상 이상 접근 검토

---

## 6. 악성프로그램 등 방지

**기술적 조치:**
- 백신·안티멀웨어 설치 (최신 업데이트)
- 침입탐지 시스템(IDS) 또는 침입방지 시스템(IPS)
- 방화벽 설정

**관리적 조치:**
- 정기적 보안 점검 (월 1회 이상)
- 보안 패치 적용 (발표 후 30일 이내 권장)

---

## 7. 물리적 보안

**서버실·기계실:**
- 출입 제한 (카드키·CCTV)
- 금고·보관함 사용

**인쇄·복사 보안:**
- 개인정보 포함 출력물: 별도 보관/파기
- 복합기 하드드라이브 초기화 (폐기 시)

---

## 8. 재해·재난 대비

**백업:**
- 개인정보 정기적 백업 (주 1회 이상)
- 백업본 분리 보관 (다른 지역)
- 복구 및 테스트 정기 실시

**복구 계획:**
- 재해 발생 시 복구 절차 사전 수립
- 복구 시간 목표(RTO) 설정
- 담당자 역할 분담

---

## 9. 파기

**파기 시점:**
- 보유기간 경과 시
- 이용 목적 달성 시

**파기 방법:**
- 전자 파일: 복구 불가능한 영구 삭제(Secure Delete)
- 출력물: 파쇄·소각
- 저장 매체: 물리적 파괴 또는 초기화

**기록:** 파기 일시, 방법, 담당자 기록 보관

---

## 10. 출력·복사 시 보호

**출력 제한:**
- 개인정보 포함 출력 최소화
- 출력 시 로그 기록

**폐기:**
- 팩스·프린터 하드드라이브 초기화
- 복합기 용지함 비우기

---

## CPPG 영역4 연계

이 기준이 시험의 **영역4(30%) - 개인정보의 보호조치**의 핵심입니다.

**출제 포인트:**
- 암호화 대상·방법
- 접근통제·권한관리
- 접속 기록 보관 기간(3개월 이상)
- 악성프로그램 방지
- 물리적 보안
- 파기 방법
- 백업·복구 계획

---

## 참고: 기술 용어 해석

| 용어 | 의미 |
|------|------|
| **IDS** | 침입탐지시스템 (침입 감지만) |
| **IPS** | 침입방지시스템 (침입 자동 차단) |
| **VPN** | 가상사설망 (암호화된 원격 접속) |
| **방화벽** | 네트워크 출입 통제 |
| **SSL/TLS** | 웹 전송 암호화 프로토콜 |
| **RTO** | 복구시간목표(Recover Time Objective) |
| **Secure Delete** | 복구 불가능한 영구 삭제 |
